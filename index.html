AI 協作開發、提示工程與架構佐證說明

1. 單頁全功能組態 (Single-File SPA Architecture)

本專案採用高效能單頁式架構 (Vanilla JS + Tailwind CSS CDN)，將 HTML 語意化結構、Tailwind 樣式設計、購物車狀態流轉、訂單與 50% 違約金計算機制，以及 Gemini LLM API 串接無縫整合於單一檔案中。

2. 提示工程 (Prompt Engineering) 關鍵規劃策略

  • 系統角色設定 (System Instruction)： 明確賦予 AI 「BK 家具工作室專業選購顧問」之 Persona，限定回應語調溫和專業，並嚴格遵循店內「本島專車配送」與「取貨 3 天內取消扣 50% 違約金」之商業規範。
  • 結構化 Prompt 設計： 結合 `gemini-3-flash-preview` 端點，透過動態上下文 (Context Window) 帶入展示商品清單與客戶即時查詢。

3. 五大評分標準對應檢核點佐證

✅ 1. HTML & 表單 (20分) 包含 header, nav, main, section, article, footer, aside 以及完整驗證表單。
✅ 2. CSS & RWD (20分) Tailwind CSS 自訂大地色系，完整支援 Mobile/Tablet/Desktop 自適應。
✅ 3. JS & 互動 (20分) 購物車動態計算、搜尋篩選、訂單查詢與配送前3天取消/50%違約金邏輯。
✅ 4. 本地 AI 串接 (20分) 右下角 BK AI 顧問浮動視窗，串接 Gemini API 提供即時對話與選購建議。
